ChemRxiv analytical characterization data

The purpose of this repository is to collect analytical characterization data from ChemRxiv preprints for testing cheminformatics methods, such as NMR-to-structure inference, on novel molecules.

We do best-effort extraction without post-processing into a simple, structured HTML format, so you can easily transform the data into your own format using an LLM.

Refer to the original publications for licensing details, typically CC BY 4.0 | CC BY-NC 4.0 | CC BY-NC-ND 4.0.
